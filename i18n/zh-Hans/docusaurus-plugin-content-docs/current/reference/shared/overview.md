# Shared 包概览

`@vef-framework-react/shared` 是框架中通用的纯函数基础包。除内部使用的少量浏览器 API（`crypto`、`atob`/`btoa`）外，不依赖 React 或 DOM。它主要包含：

1. 类型工具
2. 日期、格式化与校验辅助函数
3. 事件、对象、树、路径与字符串工具
4. 颜色与拼音相关辅助函数
