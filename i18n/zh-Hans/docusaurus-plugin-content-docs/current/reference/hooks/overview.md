# Hooks 包概览

`@vef-framework-react/hooks` 包含两类导出：

1. 由 VEF 维护的页面级 hooks
2. 通过统一稳定的包入口重新导出的第三方 hooks

## 如何阅读本节

- 关于权限、数据字典、选项转换和加载状态检查，请从 [VEF Hooks](./vef-hooks.md) 开始。
- 关于框架重新导出的 Mantine 或热键 hooks，请参阅[上游 Hook 导出](./upstream-hooks.md)。
